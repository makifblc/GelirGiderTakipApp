# Basit Gelir-Gider Takip Uygulaması (C# WinForms & MySQL)

Bu proje; kişisel finans işlemlerinizi (gelir ve giderlerinizi) kolayca yönetebilmeniz için C# Windows Forms ve MySQL kullanılarak geliştirilmiş **basit, şık ve modern** bir masaüstü uygulamasıdır.

## 🚀 Özellikler
* **Gelir & Gider Yönetimi:** Yeni işlemler ekleyin, mevcut kayıtları güncelleyin veya silin.
* **Kategori Bazlı Filtreleme:** İşlemlerinizi kategorilere göre filtreleyerek anlık olarak inceleyin.
* **Canlı Özet Paneli:** Toplam gelir, toplam gider ve net bakiye takibini modern kartlar üzerinden yapın.
* **MySQL Veritabanı Entegrasyonu:** Verileriniz güvenli ve kalıcı bir şekilde veritabanında saklanır.
* **Modern Arayüz Tasarımı:** Özel renk paleti ve yuvarlatılmış modern buton yapısıyla tasarlandı.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C# (.NET Framework / .NET Core)
* **Arayüz:** Windows Forms (Code-Behind tabanlı özel tasarım)
* **Veritabanı:** MySQL (`MySql.Data`)

## ⚙️ Kurulum ve Çalıştırma
1. Bu projeyi bilgisayarınıza klonlayın veya indirin.
2. MySQL sunucunuzda `finans_db` adında bir veritabanı oluşturun ve gerekli tabloyu (`islemler`) ekleyin.
3. `Form1.cs` içerisindeki `connectionString` alanını kendi MySQL kullanıcı adı ve şifrenize göre düzenleyin.
4. Visual Studio ile projeyi açıp **`F5`** tuşuna basarak çalıştırabilirsiniz!
